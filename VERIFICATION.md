# Проверка локального поиска

8 ноября 2026 года, Linux, Python 3.12. Установка зависимостей и pip check прошли. Pytest: 37 тестов прошли. Сценарий Streamlit подтвердил, что сохранение и индексация PDF проходят без ключа и HTTP-запросов. При вопросе тест подменял только OAuth и генерацию ответа GigaChat. Отдельный тест проверил поиск по русской словоформе и отсутствие результата для нерелевантного вопроса. Настоящий API и macOS не проверялись. Измерения качества RAG не проводились.

# Проверки после перехода на GigaChat

Дата: 24 октября 2026 года. ОС проверки: Linux x86_64, Python 3.12. Настоящий API-ключ не предоставлен. Реальные запросы к GigaChat, включая OAuth, embeddings и chat/completions, не выполнялись.

## Изменённые файлы

- `app.py`: загрузка нескольких PDF, локальное сохранение, кнопка индексации, вопросы и источники; пояснение расхода API-токенов.
- `config.py`, `.env.example`: настройки GigaChat, HTTPS-адресов, сертификата, моделей и лимита загрузки. В рабочей папке создан пустой `.env`, без реального ключа.
- `rag/embeddings.py`, `rag/llm.py`, `rag/pipeline.py`, `rag/retriever.py`: GigaChat вместо OpenAI, отдельный идентификатор модели индекса, проверка несовместимости до API-запроса.
- `requirements.txt`, `constraints.txt`, `requirements-lock.txt`: HTTPX вместо OpenAI SDK; версии проверенного чистого окружения.
- `tests/test_api.py`, `tests/test_app.py`, `tests/test_retrieval.py`: тесты нового API и интерфейса.
- `README.md`, `VERIFICATION.md`: актуальные инструкции и фактические результаты.

## Добавленные файлы

- `rag/gigachat_client.py`: REST-клиент, OAuth, обновление токена, включённый TLS и сообщения об ошибках без секретов.
- `rag/uploads.py`: локальная проверка и сохранение PDF с безопасным именем, без перезаписи другого содержимого.
- `tests/test_uploads.py`: проверки загрузки PDF.
- `tests/conftest.py`: запрет настоящего HTTPX HTTP-транспорта во всём pytest; разрешены только подменённые ответы.
- `certs/russian_trusted_root_ca.pem`, `certs/README.md`: официальный публичный корневой сертификат и его происхождение/отпечаток.

Парсер, chunker, SQLite-хранилище и арифметика четырёх метрик сохранены. Существующий проект обновлён на месте, новый проект с нуля не создавался.

## Что осталось непроверенным

- Настоящая авторизация по пользовательскому Authorization key и доступность конкретного тарифа/Scope.
- Реальные embeddings, ответы GigaChat, расход токенов и правильность ответов по методичке МИФИ.
- Фактическое HTTPS-соединение с GigaChat: локальная проверка сертификата не проверяет цепочку реального сервера и доступность сети пользователя.
- Запуск на macOS и Python 3.11: доступные проверки выполнены только на Linux/Python 3.12.
- Значения Faithfulness, Context Precision, Context Recall, Citation Accuracy на реальных ответах. Без живого прогона и ручной разметки результаты не заявляются.

Платные запросы без подтверждения пользователя не выполнялись. Внутри приложения пользователь сам запускает API-операции кнопками индексации и ответа. Фоновой проверки ключа или автоматической индексации при старте нет.
